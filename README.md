# Saffron Table

A dark, luxury restaurant landing page built with HTML, CSS and Vanilla JavaScript.

## Features
- Semantic HTML (header, nav, main, section, article, footer)
- Responsive: Flexbox, Grid and Media Queries (mobile, tablet, desktop)
- Animated images: hero slider with zoom, scrolling photo strips, curtain reveal, parallax, hover zoom and 3D tilt on dishes
- JavaScript: hamburger menu, modal popup, form validation, hero slider, menu tabs built with the DOM, review slider, number counters, scroll reveal
